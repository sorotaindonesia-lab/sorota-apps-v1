# Frontend Manual Setup Notes

Frontend sudah disetup oleh owner. Silahkan pelajari yahh setupnya itu, masih kosongan kok.

Backend harus menyediakan API untuk halaman berikut:

- Login/Admin auth
- Dashboard overview
- Customer list
- Add customer
- Customer detail
- Business mapping
- Training Center
- Knowledge Base
- Response Examples
- Bot Rules
- Skill Settings
- Early Warning Review
- Usage Dashboard
- Admin AI Command Center

Recommended frontend stack:

```text
Next.js
TypeScript
Tailwind CSS
shadcn/ui
Recharts
```

Use `docs/08-api-contracts.md` as API contract.
